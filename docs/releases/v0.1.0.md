# Thug-Fugu v0.1.0

Thug-Fugu v0.1.0 is the first tagged release of the local-first, multi-role LLM
orchestrator.

## Highlights

- Multi-role worker fan-out with synthesis, adaptive coordination, verifier
  retries, request deadlines, and usage accounting.
- Ollama, OpenAI-compatible, and offline echo backends.
- Model pools with failover, cooldown, active health probes, and a bounded HTTP
  request queue.
- OpenAI-compatible chat-completions endpoint with direct and synthesizer token
  streaming, final usage chunks, and opt-in progress events.
- Allow-listed local tool execution for explicit and backend-generated
  synthesizer tool calls, limited to one generated execution round.
- Claude Code MCP integration through `consult_thug_fugu`.
- Security safeguards including loopback-default binding and redacted backend
  errors/health endpoint labels.

## Install from source

```bash
git clone https://github.com/masa-san-jp/Thug-Fugu.git
cd Thug-Fugu
git checkout v0.1.0
python -m pip install .
```

Development tools:

```bash
python -m pip install '.[dev]'
```

## Verification

- Python 3.9, 3.10, 3.11, and 3.12 CI
- 208 unit tests
- 86% overall branch coverage (85% minimum)
- Ruff lint and format checks
- Source distribution and wheel build/install smoke test

## Known limits

- The built-in HTTP server is intended for loopback/private-network use and
  does not include production TLS or authentication.
- Backend-generated tool execution is synthesizer-only and limited to one
  generated tool round.
- Parallel ensembles and unsupported streaming paths use buffered SSE.
- Dynamic endpoint discovery and distributed scheduling are not included.
